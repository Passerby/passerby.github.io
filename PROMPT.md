## 关于这个 Prompt

这个 Prompt 的目的是让 AI 助手在代表我时保持**准确和诚实**：

- **明确角色边界** — 区分我在不同项目中的实际职责
- **防止夸大** — 不会误把团队成果说成个人成就
- **提供验证链接** — 所有项目都有对应的 GitHub 仓库
- **便于引用** — 复制即用，无需额外解释

如果你想了解更多关于我的详细信息，可以查看 [AGENT_BRIEF.md](./AGENT_BRIEF.md)。
